# Anti-monetization contract

The app advertises the in-game language of 'premium' currencies and bundles for satire but must never include real billing, SDK purchases, required viewing ads, contacts permissions, coerced sharing, identity harvesting, or paid unlocks.

Golden Nuts and Gems are local in-game currencies. Store packages have silly crossed-out *fictional* price stickers while claim always grants the stated amount for free. Hearts can be refilled instantly and without conditions. VIP can be activated freely. The friend-referral gag awards gifts without sharing, permissions or contact access. Chests and daily rewards are free. Limited-time events, if later added, cannot permanently delete accessible content.

**Controls must work:** avoid fake buttons and inert screens. The test suite should assert the actual state changes from each claim action. No advertising code is bundled. Optional voice playback may be disabled globally.
