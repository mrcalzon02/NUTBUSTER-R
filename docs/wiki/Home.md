# NUTBUSTER development wiki (mirror)

**Canonical repo:** https://github.com/mrcalzon02/NUTBUSTER-R/tree/main

**Identity:** Offline-first nut-themed match-three with every absurdly exploitative genre feature presented and fully redeemable without ads, real money, waiting, or contact harvesting. Do not replace the old glossy sprites with the later labeled board sheet.

**Platform:** Android API 26 minimum, API 36 target (ReverieVR compatibility), same game built for desktop browser/Electron.

## Starting status

- Game core plus working menu/store/rewards UI added.
- Nutvale Homestead expansion phase 2 added: 44 plots across five gated grounds, five property upgrades, 57 collectible decorations, eight avatars, eight companions, five set prizes, 15 awards, opt-in prestige sharing, and the existing $0 checkout. Legacy 12-slot saves migrate without inventing rewards.
- Android native wrapper added, not yet device-built.
- Desktop browser/Electron launch described, not yet packaged installer.
- The local audio catalog currently inventories 19 announcer clips, four reaction grunts, 17 SFX clips, and one music loop (41 files), with recorded source IDs and checksums. Voice, effects, and music remain independent.
- Owner source artwork is supplied in a separate asset archive; copy it into the repo to make APK/desktop art complete.
